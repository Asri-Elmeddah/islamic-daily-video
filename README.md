# مولد فيديو الآيات القرآنية (Reels)

## قبل التشغيل
1. ثبت المتطلبات:
   pip install -r requirements.txt --break-system-packages
   (تأكد أن ffmpeg مثبت فالنظام: ffmpeg -version)

2. **الخلفية**: بدل `assets/background.png` بصورتك النظيفة
   (بلا أي نص مطبوع دائم عليها — النص كيتزاد أوتوماتيكيا من الكود).

3. **الخط**: خط Amiri موجود جاهز فـ `fonts/`. تقدر تبدلو بخط عربي آخر
   إذا حبيت، بس بدل المسار فـ `config.json`.

4. عدل `config.json` حسب حاجتك:
   - "reciter_name_ar": اسم القارئ يبان فالفيديو
   - "reciter_edition": هوية القارئ فـ AlQuran.cloud (افتراضي: ar.alafasy)
   - "max_video_seconds": الحد الأقصى لمدة الفيديو (افتراضي 30)
   - "override_surah_number": حط رقم سورة (1-114) إذا بغيتي تحكم يدوي،
     أو خليه null للاختيار التلقائي العشوائي (بلا تكرار قريب)

## التشغيل
    python generate_video_poster.py
    # أو تحكم يدوي فالسورة:
    python generate_video_poster.py --surah 36

الفيديو النهائي كيتولد فـ `output/`.

## كيفاش خدام
- يختار سورة عشوائيا (يتفادى آخر 40 سورة استعملهم، مسجلين فـ data/history.json)
- يجيب نص وصوت كل آية من AlQuran.cloud (edition: ar.alafasy) بداية من آية 1
- يحمل كل آية (mp3) ويحسب مدتها الحقيقية، ويكمل حتى آخر آية *كاملة*
  تدخل فحدود max_video_seconds (بلا ما يقطع آية فالنص)
- يرندر فيديو mp4: خلفية + نص الآية الحالية (يتبدل مع الوقت الحقيقي
  ديال الصوت) + بار مشغل فيه اسم السورة/القارئ كيتحرك (سكرول) لليمين
  بشكل مستمر + progress bar وعداد وقت حقيقيين
- يدمج كل ملفات mp3 ديال الآيات المختارة فصوت واحد للفيديو
- يسجل السورة/الآيات المستعملة فـ history.json باش ما يتكررش قريب
